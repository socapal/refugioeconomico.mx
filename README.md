# Refugio Económico · Policy

Portal de Refugio Económico. Refugio Económico conjunta investigaciones breves sobre la economía desde una visión de bienestar público, particularmente, desde las políticas públicas, el análisis del mercado laboral, la vivienda y los bienes públicos, así como las mediciones de bienestar social. Producimos investigación citable, replicable y orientada a la acción.

🌐 **Sitio:** https://policy.refugioeconomico.mx/

---

## 📚 Contenido

Este repositorio contiene:

- **Policy Briefs:** Documentos ejecutivos (4-6 páginas) con hallazgos y recomendaciones
- **Working Papers:** Investigaciones técnicas con metodología detallada
- **Datasets:** Bases de datos curadas y documentadas
- **Código:** Scripts de replicación en R/Python
